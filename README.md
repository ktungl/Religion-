# Faith Together（暫定名稱）

職場信仰互相理解 App：每個人設定自己的信仰，自動產生宗教日曆與提醒，自己決定要分享哪些資訊給團隊；AI 提供雙向的相處建議與母語「靜心」陪伴。介面支援越南文、印尼文、泰文、英文、繁體中文。

## 技術

- Vue 3 + Vite
- vue-router、vue-i18n（語言檔在 `src/i18n/locales/`）
- Tailwind CSS v4（色彩設定在 `src/style.css` 的 `@theme`）
- vite-plugin-pwa（可安裝到手機桌面）
- Back4App（資料庫）：只由後端 `api/_lib/store.js` 用 Master Key 存取，前端無法直接讀取
- Vercel 部署；`api/` 資料夾是後端函式，AI 的 key 只放在伺服器端

## 本機開發

```bash
npm install
cp .env.example .env.local   # 填入 Back4App 的 key
npm run dev
```

`npm run dev` 不會執行 `api/` 裡的後端函式。要連同 API 一起測試：

```bash
npm run build
npm run serve:local                       # 用 .env.local 的 Back4App key
FT_MEMORY_STORE=1 npm run serve:local      # 不連資料庫，資料存在記憶體（重開就清空）
FT_MEMORY_STORE=1 FT_TODAY=2027-02-15 npm run serve:local   # 固定日期，例如展示齋戒月
```

網址是 http://localhost:4174

## 資料夾

## AI 使用方式（作品說明書「AI 工具揭露」可引用）

- 節日說明（`api/explain.js`）：每個日子先由人工整理一份簡短的英文事實資料（`api/_lib/eventFacts.js`），AI 只能根據這份資料，用使用者的語言（中、越、印、泰、英）改寫成好懂的說明，不得自行加入經文、禱文或宗教判斷。
- 模型：Google Gemini（預設 `gemini-3.6-flash`），可用環境變數改成其他模型或 Claude。
- 同一個日子、同一個語言只產生一次，之後由 Vercel 快取，節省額度。
- AI 失敗或額度用完時，自動改顯示人工整理的資料，畫面標示「範例」；AI 產生的內容標示「AI」。

## 團隊與隱私

- 不用註冊：輸入名字和團隊代碼即可加入。建立團隊的人是主管。
- 每位成員有一組只存在自己手機上的金鑰（伺服器只存雜湊值），用來證明身分。
- Back4App 的資料表權限全部關閉，只有後端能讀寫。後端 `sharedView()` 依每個人的分享設定過濾，沒打開的內容不會送出伺服器。
- 「宗教節日」和「齋戒日子」的名稱本身可能看得出信仰；分享前畫面已說明用途。
- 離開團隊會刪除伺服器上這個人的資料。

API：`POST /api/team/create`、`join`、`me`、`view`、`leave`

## 配色

App 外框用中性深灰，信仰各有代表色（`src/style.css`、`src/lib/faithStyle.js`）。顏色旁一定附上信仰名稱，不單靠顏色辨識。

| 信仰 | 顏色 | 依據 |
|---|---|---|
| 伊斯蘭教 | 綠 `#1F7A4D` | 天堂、和平 |
| 天主教、基督教 | 紫 `#6A4C9C` | 將臨期、大齋期禮儀色 |
| 佛教 | 赭黃 `#B7791F` | 僧袍色 |
| 道教／民間信仰 | 紅 `#B3362B` | 廟宇朱紅 |
| 無特定信仰 | 灰 `#6B7280` | 中性 |

## 日期規則（`src/lib/calendar.js`）

| 信仰 | 內容 | 計算方式 |
|---|---|---|
| 佛教、道教／民間信仰 | 初一十五（吃素）、農曆節日、清明 | lunar-javascript |
| 伊斯蘭教 | 齋戒月、開齋節、宰牲節、伊斯蘭新年、聖紀節 | 瀏覽器內建 Umm al-Qura 曆，實際以看月為準，可能差一天 |
| 伊斯蘭教 | 每日五次禮拜時間 | adhan，Singapore 參數，地點台北 |
| 天主教、基督教 | 聖誕、復活節、受難日；天主教另有聖灰星期三、諸聖節 | 復活節用公曆計算法 |

尚未納入：南傳佛教（泰國）節日如衛塞節、萬佛節，日期規則與漢傳不同。

## 注意

- 語言檔的越、印、泰文需請母語人士確認。
- 宗教內容（日期規則、經文、禱文）需經各信仰的信徒審閱，AI 不自行創作宗教文本。
